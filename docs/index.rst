PREP pipeline
=============

The PREP pipeline is a standardized early-stage EEG processing pipeline. It
identifies bad channels, removes line noise without committing to a filtering
strategy, and computes a robust average reference, with an extensive reporting
facility. It runs fully automated, as a MATLAB toolbox or as an EEGLAB plugin.

If you use PREP, please cite:

    | Bigdely-Shamlo N, Mullen T, Kothe C, Su K-M and Robbins KA (2015).
    | The PREP pipeline: standardized preprocessing for large-scale EEG analysis.
    | *Front. Neuroinform.* 9:16. `doi:10.3389/fninf.2015.00016 <https://doi.org/10.3389/fninf.2015.00016>`_
